## power-switch v0.1.11

中文桌面模型与 MCP 连接器管理工具，支持 WorkBuddy、Claude Code 和 Codex。

### 本次更新

- 思考强度采用单选按钮，提供“低、中、高、超高、极致”五个中文档位；手动新增模型和通过 New API 添加模型时默认选中“高”（`high`）。兼容已有配置，保留未编辑的旧档位数据。
- Codex 配置与模型目录的默认思考档位保持一致，档位说明使用中文。Codex（OpenAI Responses）新建模型的上下文默认值为 `524288` Token，并同步写入 `model_context_window` 和模型目录；用户自定义上下文及其他协议的默认值保持不变。
- 设置中新增“配置初始化”，可选择“模型库和模型备份”与“MCP 连接器配置”两个选项，至少选择一项才能开始，也可同时选择两项。
- 初始化模型库时，先请求 New API 服务端退出，再清理本地会话和所选模型数据；若服务端退出失败，本地数据会保留，用户可重试。
- 初始化 MCP 配置时，删除用户自定义连接器，并清空内置连接器令牌。
- 初始化范围说明和确认界面明确提示：已写入 WorkBuddy、Claude Code、Codex 等 Agent 的配置，外观与路径设置，以及 Skills 均予以保留。
- 配置初始化区域的字体、字号和字重已与应用界面统一。

### 下载选择

文件名中的版本与本次标签一致：

| 系统          | 文件后缀                                 | 说明                                             |
| ------------- | ---------------------------------------- | ------------------------------------------------ |
| macOS         | `macos-universal.dmg` / `.zip`           | 同时支持 Intel 和 Apple Silicon；ZIP 内为 `.app` |
| Windows x64   | `windows-x64.msi` / `.zip`               | MSI 安装版，或免安装可执行程序                   |
| Windows ARM64 | `windows-arm64.msi` / `.zip`             | ARM64 原生应用                                   |
| Linux x64     | `linux-x64.AppImage` / `.deb` / `.rpm`   | 按发行版选择                                     |
| Linux ARM64   | `linux-arm64.AppImage` / `.deb` / `.rpm` | ARM64 原生应用                                   |

`SHA256SUMS` 包含本次发布安装包及 macOS 更新归档的 SHA-256 校验值，请以随发布页提供的清单为准。

### 安装须知

- 安装包未使用开发者证书签名或 Apple 公证，macOS 可能提示未知发布者或阻止首次打开。请确认下载来源并核对校验值。
- Windows 需要 WebView2 Runtime；MSI 可引导安装，ZIP 需要预先安装。ZIP 仍将数据保存在当前用户的 `.power-switch` 目录，不属于数据随身携带的便携版，也不保证注册 `power-switch://` 协议。
- Linux AppImage 需赋予执行权限；部分发行版还需要 FUSE。DEB/RPM 会声明所需的系统依赖。
- 正式版进入 Latest 更新通道。检查更新只读取版本清单，下载安装需要在应用内再次确认。
- 配置初始化通过隔离数据的自动化测试和演示界面验收；没有使用真实 New API 账号进行注销测试。云端构建与自动化测试通过不代表所有平台均完成真实机器安装验收，跨平台真实安装尚未全覆盖。

发布、校验、排障及正式版流程见仓库 `docs/releasing.md`。
