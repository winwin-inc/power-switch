## power-switch v0.2.1

中文桌面模型与 MCP 连接器管理工具，支持 WorkBuddy、Claude Code 和 Codex。

### 本次更新

- 全局界面采用浅色中性极简风格，统一页面标题、系统字体、间距、卡片与浅深主题。模型名称、Agent 和常用操作更醒目，协议、地址和能力标签减少视觉干扰。
- 模型卡片常驻“编辑”“测试模型”“应用到 Agent”；复制、分享与删除收进“更多操作”，支持键盘进入、Escape 关闭和焦点返回，删除仍需单独确认。
- “从 New API 添加”改为杏橙色按钮；侧栏整理业务与帮助入口，MCP 位于 SKILL 上方，保留简洁的本机存储与版本信息。
- 模型库、MCP、备份、设置、关于和新手指引统一布局。长弹窗的正文单独滚动，底部操作持续可见；补齐首次加载失败重试、空数据与筛选无结果的反馈。
- WorkBuddy、Claude Code、Codex 的手动新增和 New API 新增统一推荐上下文 `524288` Token、思考强度“高”，并在高级设置外显示默认参数建议。已有模型、复制模型、分享链接导入及用户自定义上下文继续保留原值。
- 左上角品牌加入约 1.8 秒的“蓄力—通电弹起—文字波浪—回弹”动画；短暂移入后离开也能完整播放，连续进入不叠加，悬停不循环。系统减少动态效果设置下改为静态反馈，新手指引停止自动轮播。
- 修复主题保存失败后选中状态未回滚、无法再次重试的问题，同时保留未保存的配置路径草稿。
- 修复原生 WebKit 中“更多操作”无法通过 Escape 关闭的问题；关闭后焦点回到触发按钮。
- 配置预览保留上下文容量等明确的整数参数，API Key、令牌、请求头及链接凭据继续脱敏。
- 更新检查启用 gzip 压缩传输，减少 GitHub 发布列表的传输量；对传输中断、截断 JSON/压缩流和临时网关错误进行有限退避重试。分页不会重复累加，限流和字段异常明确报错，不会把失败当作“已是最新”。
- 侧栏不再显示容易被误认为“发现更新”的失败重试图标；错误详情与检查入口保留在关于页，确认安装和重启失败时提供明确通知。
- 升级 Vite、Vitest 及相关开发依赖，并补充默认参数、焦点、主题回滚、弹窗布局、品牌动效及更新传输异常的回归测试。

### 下载选择

文件名中的版本与本次标签一致：

| 系统          | 文件后缀                                 | 说明                                             |
| ------------- | ---------------------------------------- | ------------------------------------------------ |
| macOS         | `macos-universal.dmg` / `.zip`           | 同时支持 Intel 和 Apple Silicon；ZIP 内为 `.app` |
| Windows x64   | `windows-x64.msi` / `.zip`               | MSI 安装版，或免安装可执行程序                   |
| Windows ARM64 | `windows-arm64.msi` / `.zip`             | ARM64 原生应用                                   |
| Linux x64     | `linux-x64.AppImage` / `.deb` / `.rpm`   | 按发行版选择                                     |
| Linux ARM64   | `linux-arm64.AppImage` / `.deb` / `.rpm` | ARM64 原生应用                                   |

`SHA256SUMS` 包含全部 12 个常规安装包及 macOS 更新归档的 SHA-256 校验值。

### 安装须知

- 当前安装包未使用开发者证书签名或 Apple 公证，系统可能提示未知发布者或阻止首次打开。请先确认下载来源并核对校验值。
- Windows 需要 WebView2 Runtime；MSI 可引导安装，ZIP 需要预先安装。ZIP 仍将数据保存在当前用户的 `.power-switch` 目录，不能视为数据随身携带的便携版，也不保证注册 `power-switch://` 协议。
- Linux AppImage 需赋予执行权限；部分发行版还需要 FUSE。DEB/RPM 会声明所需的系统依赖。
- 本版正式发布后进入 Latest 更新通道，已安装的正式版客户端可检查到更新。
- 检查更新只读取版本清单，下载安装需要在应用内再次确认。
- 云端构建与测试通过不代表所有平台均完成真实机器安装验收。

发布、校验、排障及提升正式版的流程见仓库 `docs/releasing.md`。
